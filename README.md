# demo1-js-engine

c++api with js binding for dll injection

This demo is used to inject into any systems or trojans for using own js api hooks 

DSL part is based on v8pp project

v8monolith.lib version is 14.3 made by github action

v8 team won't support MSVC STL, but using libc++ instead,so i stop making it
